# AI Customer Support Bot

A Telegram bot powered by Cohere AI that answers customer questions intelligently.

## Features
- Answers any customer question using AI
- Short, friendly and professional responses
- Easy to customize for any business

## How to run
1. Install dependencies:
   pip install python-telegram-bot nest_asyncio cohere
2. Add your Telegram token and Cohere API key in the code
3. Run on Google Colab

## Libraries used
- python-telegram-bot
- cohere
- nest_asyncio

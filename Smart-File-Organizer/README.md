# Smart File Organizer

A Python script that automatically organizes files into folders based on their type.

## What it does
- Images (.jpg, .png) → photos/
- Documents (.pdf, .docx) → documents/
- Videos (.mp4) → videos/
- Music (.mp3) → music/
- Archives (.zip) → archive/

## How to run
1. Set your source folder path in the script
2. Set your destination folder path
3. Run: python main.py

## Libraries used
- os
- shutil
